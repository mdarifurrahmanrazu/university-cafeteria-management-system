# university-cafeteria-management-system

### Project Description
A full-stack PHP & MySQL Cafeteria Management System featuring a Digital Wallet, Kitchen Display System (KDS), and Live Search Menu.

### Tech Stack
- PHP (Backend)
- MySQL (Database)
- HTML, CSS, JavaScript (Frontend)

### How to Run locally
1. Clone this repository.
2. Start Apache and MySQL on XAMPP.
3. Import the database tables.
4. Open `http://localhost/campusbite_db/login.php` in your browser.
